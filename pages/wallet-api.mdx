## Wallet API Methods

These Wallet API endpoints allow retrieving portfolio, balance, transaction, PNL, token, NFT, and protocol data across multiple chains, facilitating efficient wallet tracking and integration.

## Supported chains

Returns the list of blockchain networks supported by the Wallet API, along with details for a specific chain.

[Get Supported Chains](/wallet-api/chain/getsupportedchains) : Retrieves a list of all chains supported by the Wallet API. \
[Get Supported Chain By Id](/wallet-api/chain/getsupportedchainbyid) : Fetches details of a specific supported chain by its ID.

## Wallet

Provides portfolio value, net worth history, transaction history, and profit-and-loss data for EVM and non-EVM wallets.

[Get EVM Portfolio](/wallet-api/wallet/getevmportfolio) : Returns the token portfolio and balances for an EVM-compatible wallet address. \
[Get non-EVM Portfolio](/wallet-api/wallet/getnonevmportfolio) : Returns the token portfolio and balances for a non-EVM wallet address. \
[Get Historical Net Worth](/wallet-api/wallet/gethistoricalnetworth) : Retrieves the historical net worth of a wallet over time. \
[Get Transactions History](/wallet-api/wallet/gettransactionshistory) : Fetches the transaction history for a given wallet address. \
[Get PNL History](/wallet-api/wallet/getpnlhistory) : Returns the historical profit and loss (PNL) data for a wallet. \
[Get Aggregated PNL](/wallet-api/wallet/getaggregatedpnl) : Provides aggregated profit and loss data across a wallet's holdings. \
[Get PnL for Multiple Wallets](/wallet-api/wallet/getpnlformultiplewallets) : Retrieves profit and loss data for multiple wallet addresses at once. \
[Get Yield Recommendations](/wallet-api/wallet/getyieldrecommendations) : Returns yield opportunity recommendations based on a wallet's holdings.

## Token

Supplies information on supported tokens, their metadata, price symbols, and historical price data.

[Get Supported Tokens](/wallet-api/token/getsupportedtokens) : Retrieves a list of all tokens supported by the Wallet API. \
[Get Token Info By Id](/wallet-api/token/gettokeninfobyid) : Fetches detailed metadata for a specific token by its ID. \
[Get Supported Price Symbols](/wallet-api/token/getsupportedpricesymbols) : Returns the list of price symbols supported for token pricing. \
[Search Historical Prices](/wallet-api/token/searchhistoricalprices) : Searches historical price data for a specified token.

## NFT

Retrieves NFT holdings, collection data, and metadata for wallets and individual NFTs.

[Get Wallet NFTs (Non-EVM)](/wallet-api/nft/getwalletnfts) : Retrieves the NFTs held by a non-EVM wallet address. \
[Get NFT Collections](/wallet-api/nft/getnftcollections) : Fetches the NFT collections associated with a wallet. \
[Get NFT Metadata by ID](/wallet-api/nft/getnftmetadatabyid) : Returns metadata for a specific NFT by its ID. \
[Refresh NFT Metadata](/wallet-api/nft/refreshnftmetadata) : Triggers a refresh of the stored metadata for a specific NFT.

## Protocols

Provides historical yield data for DeFi protocols.

[Get APR History](/wallet-api/protocols/getaprhistory) : Retrieves the historical annual percentage rate (APR) data for a protocol.
